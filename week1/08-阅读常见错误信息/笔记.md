# 学习笔记：阅读常见错误信息

## 学到了什么
报错从**最后一行**往上看：错误类型 + 一句话说明，上面的回溯（traceback）指出出错的文件和行号。

| 报错 | 原因 | 我的实例 |
|------|------|----------|
| SyntaxError | 语法写错（少冒号/中文标点） | if 后面忘写冒号 |
| NameError | 用了未定义的变量 | 变量名拼错（sorce vs score） |
| TypeError | 类型不匹配运算 | `"abc" + 1` |
| ValueError | 类型对但值不合法 | `int("abc")` |
| IndexError | 下标越界 | `"ab"[5]` |
| IndentationError | 缩进不对 | 混用 Tab 和空格 |

## 心得
- 报错不是坏事，它直接告诉你**哪一行、什么问题**，比肉眼找快多了
- 看不懂英文错误信息就搜错误类型名，几乎都有中文解释
