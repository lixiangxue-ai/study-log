# 学习笔记：算术、比较和逻辑运算

## 学到了什么
- 七种算术运算：+ - * / // % **
- `/` 结果永远是 float；`//` 整除向下取整；`%` 取余；`**` 幂
- 比较运算返回 bool：== != > < >= <=（== 是判断，= 是赋值！）
- 逻辑运算：and / or / not，优先级 not > and > or
- 链式比较可以写：`0 < x < 100`，Python 特色

## 我踩过的坑
- `10 // 3` 是 3，`10 / 3` 是 3.3333...，考试题专门考这个区别
- 把 `==` 写成 `=` 不报语法错但逻辑全错
