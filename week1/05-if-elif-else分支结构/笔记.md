# 学习笔记：if-elif-else 分支结构

## 学到了什么
- 结构：if 条件: → elif 条件: → else:，冒号和缩进（4 空格）都不能少
- 条件从上往下依次判断，命中一个就跳过剩下全部
- 单行条件表达式：`"偶数" if n % 2 == 0 else "奇数"`
- 范围判断要用 if-elif 串联并从大到小（或从小到大）排，否则 86 会被 >=60 先截走

## 我踩过的坑
- elif 写成 else if（这是 C/Java 的写法，Python 不认）
- 忘了冒号，报 SyntaxError
- 条件顺序写反导致等级判断全错，改成 >=90 开始递减就对了

## 验证
见 demo_branch.py：86 → 良好；95 → 优秀；42 → 不及格，全部符合预期。
