# 学习笔记：循环嵌套

## 学到了什么
- 外层管"行"，内层管"行里的每一项"
- 内层循环的范围经常依赖外层变量，如 `for j in range(1, i + 1)` 是三角形的关键
- 打印一行多项时用 `print(x, end=" ")` 或先拼进列表再 join，换行由外层控制
- 水仙花数虽是单层循环，但数位拆分 a//100、b//10%10、c%10 是必会套路

## 我踩过的坑
- 内层 print 没处理 end，一行一个数字全竖着排
- 三角形乘法表把 range(1, i+1) 写成 range(1, 10)，打成整张方块表
