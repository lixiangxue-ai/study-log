4.（7 分） 用循环找出所有的三位数「水仙花数」并逐行输出。水仙花数是指一个三位数，它每一位数字的立方和恰好等于它本身（例如 153 = 1³ + 5³ + 3³）。来源：教材循环章节经典原题
【输入】无 【输出示例】（每个水仙花数一行，从小到大） 153 370 371 407

5.（8 分） 从键盘输入若干个成绩（用空格分隔），统计并输出：平均分（保留 2 位小数）、最高分、最低分、及格（≥60）人数。来源：课件任务 4 原题改编

6.（8 分） 编写程序：将列表中最小的元素与第一个元素交换位置，输出交换后的列表。要求不使用 sorted 等排序函数。来源：教材第 4 章原题
【输入示例】 5 3 9 1 7 【输出示例】 [1, 3, 9, 5, 7]
✍️ 你的代码：
参考答案： nums = [int(x) for x in input().split()] mi = 0 for i in range(1, len(nums)): if nums[i] < nums[mi]: mi = i nums[0], nums[mi] = nums[mi], nums[0] print(nums) 评分：找最小下标 4 分；交换 2 分；输出 2 分。
7.（9 分） 从键盘输入 n 个整数（空格分隔），把它们组成一个元组 t，输出：① 该元组；② 最大值及其首次出现的下标；③ 元组中整数 3 出现的次数。来源：原创（元组综合应用）
【输入示例】 4 3 9 3 1 【输出示例】 (4, 3, 9, 3, 1) 最大值:9 首次下标:2 3的次数:2
✍️ 你的代码：
参考答案： nums = [int(x) for x in input().split()] t = tuple(nums) print(t) m = max(t) print("最大值:%d 首次下标:%d" % (m, t.index(m))) print("3的次数:%d" % t.count(3)) 评分：构造元组 3 分；max 与 index 3 分；count 3 分。
8.（11 分） 给定一个字符串 s，找到 s 中最长连续相同字符。若有多个字符连续长度相同，返回最先出现的那个字符。输出该字符、最大长度和该字符所有最长序列的起始位置（下标从 0 开始）。来源：2025 年全国高校计算机能力挑战赛编程题原题（题目 1、题目 3 合并）
【示例输入1】 aaabbbaaa　　【输出1】 a 3 0 【示例输入2】 aaabbbaaacccbbb 【输出2】 a 3 0,6 【示例输入3】 aabbbcc　　【输出3】 b 3 2
✍️ 你的代码：
参考答案： s = input().strip() max_char, max_len = s[0], 1 cur_char, cur_len = s[0], 1 pos = [0] for i in range(1, len(s)): if s[i] == cur_char: cur_len += 1 else: cur_char, cur_len = s[i], 1 if cur_len > max_len: max_len = cur_len max_char = cur_char pos = [i - cur_len + 1] elif cur_len == max_len and cur_char == max_char and i < len(s) - 1: pos.append(i - cur_len + 1) print(max_char, max_len, ",".join(map(str, pos))) 评分：单趟扫描结构与连续段维护 5 分；更新最大 3 分；同长起始位置收集 2 分；输出格式 1 分。

（附加 5 分） 给定正整数 n（1 ≤ n ≤ 100），求最少需要多少个完全平方数（1, 4, 9, 16, …）相加等于 n，输出这个数量。提示：可用列表 squares 保存 100 以内的平方数，再用多重循环枚举。来源：2025 年全国高校计算机能力挑战赛编程题原题（完美平方数分解，限定小规模）
【输入示例1】 12　【输出1】 3 （12 = 4+4+4） 【输入示例2】 13　【输出2】 2 （13 = 4+9）
✍️ 你的代码：
