## 收获与易错点

- `9 ** 0.5` 结果是浮点数 3.0，与整数相加得 6.0 而不是 6
- 单元素元组必须写 `(5,)`，`(5)` 只是带括号的整数
- 切片赋值 `lst[1:] = [7,8]` 会整体替换，长度可变
- `append` 把整个列表当一个元素，`extend` 才是拆开拼接
- 完全平方数分解的枚举要注意把 0 也放进候选列表，否则"用几个数"统计不出正确值
